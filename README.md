📦 App Móvil para el Banco de Alimentos de México
📱 Descripción del Proyecto
Este proyecto es una aplicación móvil desarrollada específicamente para Android, creada con el propósito de mejorar la productividad de todos los colaboradores del Banco de Alimentos de México.

🎯 Objetivo
Optimizar la gestión de tareas dentro de la organización mediante la organización eficiente de equipos de trabajo, asignación de líderes y delegación de responsabilidades.

🧠 Funcionalidades Principales
Gestión de equipos de trabajo.

Asignación de líderes de equipo.

Creación de tareas personalizadas.

Asignación inteligente de tareas al miembro más capacitado del equipo.

Visualización de tareas en un sistema tipo Kanban para facilitar el seguimiento.

🛠️ Tecnologías Utilizadas
Android SDK

Framework usado: React Native, Flutter, Kotlin

Backend/API: OpenAI

Base de datos: Mongo DB

🤝 Agradecimientos
Este proyecto fue desarrollado con el objetivo de apoyar al Banco de Alimentos de México en su misión de ayudar a quienes más lo necesitan, mejorando la eficiencia y organización interna a través de la tecnología.
